# Camp Buddy Scoutmaster Season — Patch de traduction française (non officiel)

## Présentation

Patch de traduction française non officiel pour le visual novel BL *Camp Buddy Scoutmaster Season*, développé par BLits.  
Compatible avec le DLC *Camp Buddy: Scoutmaster Season - Side Stories*.

* [Site officiel](https://www.blitsgames.com/product/camp-buddy-scoutmaster-season/)
* [Steam](https://store.steampowered.com/app/1968430/Camp_Buddy_Scoutmaster_Season/)
* [Itch.io](https://blitsgames.itch.io/scoutmaster-season)

### Bande-annonce officielle

[![Demo](https://img.youtube.com/vi/49f89d-goVc/maxresdefault.jpg)](https://www.youtube.com/watch?v=49f89d-goVc)

### Remarques importantes

* Le patch ne contient aucune donnée du jeu.
* Une copie du jeu obtenue légalement est nécessaire pour utiliser ce patch.
* Pour bénéficier de la traduction des Side Stories, le DLC *Camp Buddy: Scoutmaster Season - Side Stories* est requis.
* La traduction de ce patch a été réalisée avec l'assistance d'une IA.

## Installation

### Télécharger le patch

1. Rendez-vous sur la [page Releases](../../releases) et téléchargez la dernière version du fichier `zzzzz_patch_fr.rpa`.
2. Placez le fichier `zzzzz_patch_fr.rpa` dans le dossier `Camp Buddy Scoutmaster Season` > `game`.

### Changement de langue

Il n'est pas possible de changer la langue en cours de jeu.  
Pour jouer en anglais, quittez le jeu et déplacez le fichier `zzzzz_patch_fr.rpa` hors du dossier du jeu.

## Désinstallation du patch

Quittez le jeu, puis supprimez le fichier `zzzzz_patch_fr.rpa`.
