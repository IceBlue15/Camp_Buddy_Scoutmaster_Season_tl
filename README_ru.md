# Camp Buddy Scoutmaster Season — Неофициальный русский патч

## Описание

Неофициальный русский патч для BL визуальной новеллы *Camp Buddy Scoutmaster Season*, разработанной BLits.  
Совместим с DLC *Camp Buddy: Scoutmaster Season - Side Stories*.

* [Официальный сайт](https://www.blitsgames.com/product/camp-buddy-scoutmaster-season/)
* [Steam](https://store.steampowered.com/app/1968430/Camp_Buddy_Scoutmaster_Season/)
* [Itch.io](https://blitsgames.itch.io/scoutmaster-season)

### Официальный трейлер

[![Demo](https://img.youtube.com/vi/49f89d-goVc/maxresdefault.jpg)](https://www.youtube.com/watch?v=49f89d-goVc)

### Важные замечания

* Патч не содержит данных игры.
* Для использования патча необходима легально приобретённая копия игры.
* Для перевода Side Stories требуется DLC *Camp Buddy: Scoutmaster Season - Side Stories*.
* Перевод данного патча основан на существующем неофициальном русском переводе и адаптирован для Steam-версии с помощью ИИ.
* В случае обращения правообладателя данный патч будет незамедлительно удалён или изменён.

## Установка

### Скачать патч

1. Перейдите на [страницу Releases](../../releases) и скачайте последнюю версию файла `zzzzz_patch_ru.rpa`.
2. Поместите файл `zzzzz_patch_ru.rpa` в папку `Camp Buddy Scoutmaster Season` > `game`.

### Смена языка

Сменить язык во время игры невозможно.  
Чтобы играть на английском, выйдите из игры и переместите файл `zzzzz_patch_ru.rpa` из папки игры.

## Удаление патча

Выйдите из игры и удалите файл `zzzzz_patch_ru.rpa`.
