# Camp Buddy Scoutmaster Season 非公式日本語パッチ

## 概要

BLits制作のBLノベルゲーム、『Camp Buddy Scoutmaster Season』 の非公式日本語パッチです。  
DLC『Camp Buddy: Scoutmaster Season - Side Stories』にも対応しています。

* [公式サイト](https://www.blitsgames.com/product/camp-buddy-scoutmaster-season/)
* [Steam](https://store.steampowered.com/app/1968430/Camp_Buddy_Scoutmaster_Season/)
* [Itch.io](https://blitsgames.itch.io/scoutmaster-season)

### 公式PV

[![Demo](https://img.youtube.com/vi/49f89d-goVc/maxresdefault.jpg)](https://www.youtube.com/watch?v=49f89d-goVc)

### 注意事項

* パッチにはゲームのデータは含まれていません。
* ご利用には正規に入手されたゲーム本体が必要です。
* Side Stories の翻訳を利用するには、DLC『Camp Buddy: Scoutmaster Season - Side Stories』が必要です。

## 設定方法

### パッチファイルをダウンロード

1. [Releases ページ](../../releases) から最新版の `zzzzz_patch_ja.rpa` ファイルをダウンロードしてください。
1. ダウンロードした `zzzzz_patch_ja.rpa` ファイルを `Camp Buddy Scoutmaster Season` > `game` フォルダ内に配置してください。

### 言語切り替え

このゲームはプレイ中に言語を切り替えることはできません。  
英語でプレイしたい場合は、ゲームを終了し `zzzzz_patch_ja.rpa` ファイルをゲーム外のフォルダに移動してください。

## パッチの削除方法

ゲームを終了し、`zzzzz_patch_ja.rpa` ファイルを削除してください。
